# Assnetes (1Ж:Оркестратор 8)

[English version](README.md)

Assnetes — дистрибутив Kubernetes для бухгалтерии. Всё, что человек пишет и читает, — по-русски, на языке 1С:Предприятия:

- **манифесты — модули на языке 1С**, а не YAML;
- **операторы тоже пишутся на языке 1С**, а обработчики называются как события модуля объекта;
- **`1сctl`**, командная строка, понимает и отвечает по-русски и разговаривает как бухгалтерия;
- пакетный менеджер ставит в кластер 1С:Предприятие, 1С:Бухгалтерию, 1С:Управление торговлей, 1С:CRM и 1С-Битрикс, а их операторы ведут весь жизненный цикл.

Это шутка, которая работает: API-сервер, etcd и все контроллеры настоящие, и то, что они делают, — тоже.

> **Состояние:** ранняя стадия. Язык, манифесты, `1сctl` и среда исполнения операторов работают, на тестовом кластере крутятся пять обработок. Операторы продуктов 1С в работе. См. [дизайн](docs/design.ru.md).

> Assnetes — неофициальная пародия. Фирма «1С» её не делала, не одобряла и не поддерживает. «1С», «1С:Предприятие» и названия продуктов 1С — товарные знаки фирмы «1С»; программ фирмы «1С» Assnetes не поставляет: дистрибутив платформы и лицензию вы приносите свои.

## Манифест

```bsl
#Область Витрина

Развёртывание = Новый Развёртывание("Витрина", "Ромашка");
Развёртывание.Метаданные.Метки.Вставить("приложение", "витрина");
Развёртывание.Спецификация.Реплики = 2;
Развёртывание.Спецификация.Отбор.ПоМеткам.Вставить("приложение", "витрина");
Развёртывание.Спецификация.Шаблон.Метаданные.Метки.Вставить("приложение", "витрина");

Контейнер = Развёртывание.Спецификация.Шаблон.Спецификация.Контейнеры.Добавить();
Контейнер.Имя = "веб";
Контейнер.Образ = "nginx:1.29-alpine";
Контейнер.Ресурсы.Запросы.Процессор = "50m";

Провести(Развёртывание);

#КонецОбласти
```

```console
$ 1сctl провести --файл витрина.bsl
✓ Развёртывание «Витрина» проведено
  — Провела «Витрина». В следующий раз — со служебкой. (Тамара Петровна)
$ 1сctl получить поды --подразделение Ромашка
ИМЯ                        ГОТОВО   ФАЗА       ПЕРЕЗАПУСКИ   СОСТОЯНИЕ    ВОЗРАСТ
vitrina-74849bf66d-7xft9   1/1      Работает   0             ✓ проведён   23 сек
```

Виды, поля, имена и метки переводятся по дороге в API и обратно: `Развёртывание` — это Deployment, `Спецификация.Реплики` — `spec.replicas`, имя «Витрина» становится `vitrina`, а оригинал хранится в аннотации, поэтому `1сctl выгрузить развёртывание витрина` возвращает манифест по-русски. Виды самого дистрибутива хранят кириллические поля прямо в API: Kubernetes их принимает.

## Оператор

Оператор — это «обработка»: модуль и, если у неё свои виды, их описание.

```bsl
&Обработка(Вид = "АктСверки")
Процедура ОбработкаПроведения(Объект, Отказ) Экспорт
	// привести мир к объекту
КонецПроцедуры

&ПроверкаЗаполнения(Виды = "Развёртывание", Операции = "Создание, Изменение")
Процедура ОбработкаПроверкиЗаполнения(Объект, Отказ, Контекст) Экспорт
	// не пустить в кластер то, чему там не место
КонецПроцедуры

&Расписание("17 * * * *")
Процедура УдалитьПомеченные() Экспорт
	// регламентное задание
КонецПроцедуры
```

Остальное делает среда исполнения `obrabotchik`: наблюдение и очереди, server-side apply, владельцы, финализаторы, состояние, события, вебхуки допуска со своим сертификатом, расписания и монопольный режим. Модули видят кластер через `Кластер`, у них есть HTTP с проверкой сертификатов, чтение XML и JSON языка.

С дистрибутивом идут пять обработок, в [obrabotki](obrabotki):

| Обработка | Что делает |
|---|---|
| [Производственный календарь](obrabotki/proizvodstvennyj-kalendar) | загружает официальный производственный календарь и не даёт выкатывать в праздники, выходные и в предпраздничный день после обеда — если только нет служебной записки |
| [Курсы валют](obrabotki/kursy-valyut) | берёт курсы ЦБ РФ и считает стоимость каждого подразделения по запросам ресурсов, в рублях и в валютах |
| [Дата запрета изменения](obrabotki/data-zapreta) | закрывает период: объекты, созданные до даты подразделения, может менять только главный бухгалтер |
| [Удаление помеченных](obrabotki/udalenie-pomechennyh) | удаляет помеченное на удаление, только если на объект никто не ссылается, а иначе говорит, кто ссылается |
| [Акт сверки](obrabotki/akt-sverki) | сверяет кластер с манифестами в Git и составляет акт сверки |

## Устройство

| Путь | Что |
|---|---|
| `pkg/bsl` | интерпретатор языка 1С |
| `pkg/perevod` | перевод между русским и API |
| `pkg/manifest` | манифесты на языке 1С |
| `pkg/golos` | голос бухгалтерии |
| `pkg/cli`, `cmd/1sctl` | `1сctl` |
| `pkg/obrabotka`, `cmd/obrabotchik` | среда исполнения операторов |
| `pkg/metadannye` | CRD из описаний видов |
| `obrabotki` | обработки, которые идут с дистрибутивом |

## Сборка

```bash
go build -o bin/1сctl ./cmd/1sctl
go build -o bin/obrabotchik ./cmd/obrabotchik
go test ./...
```
